# Orbitoshopv2 Database Baseline

`orbitoshopv2-client-schema-2026-09-02.sql` is a schema-only PostgreSQL
dump of the Orbitoshopv2 client development Supabase database captured
before the V1 stabilization work began.

Captured: 2026-09-02

This file is a historical baseline.

DO NOT modify or overwrite it.

All database changes made after this baseline must be introduced through
version-controlled migrations under:

supabase/migrations/

No customer data is contained in the baseline dump.
